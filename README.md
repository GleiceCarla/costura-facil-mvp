
# Costura Fácil — MVP

## Sobre o projeto

O Costura Fácil é um projeto acadêmico de desenvolvimento de software voltado à organização de encomendas de uma oficina doméstica de costura.

A proposta surgiu da necessidade de centralizar informações sobre clientes, serviços e prazos de entrega, anteriormente organizadas por meio de cadernos, mensagens e anotações.

## Objetivo

Desenvolver uma aplicação web simples, acessível e responsiva para auxiliar uma costureira autônoma no gerenciamento de suas encomendas.

## Funcionalidades planejadas

- Cadastro de clientes
- Cadastro de pedidos de costura
- Consulta de encomendas
- Atualização do status dos pedidos
- Edição de informações dos serviços
- Autenticação para acesso ao sistema

### Status dos pedidos

- Recebido
- Em andamento
- Pronto
- Entregue

## Tecnologias previstas

- Python 3.12
- Flask 3.1
- HTML5
- CSS3
- Jinja2
- SQLite
- Pytest

## Arquitetura

O sistema seguirá uma arquitetura monolítica organizada em três camadas:

1. Apresentação: interface web responsiva.
2. Regras de negócio: validação e processamento com Python e Flask.
3. Persistência: armazenamento de dados em SQLite.

## Segurança e acessibilidade

O projeto prevê autenticação de usuário, armazenamento seguro de senhas, validação de entradas e proteção das informações.

A interface será desenvolvida com linguagem simples, contraste adequado, campos identificados e navegação adaptada a dispositivos móveis.

## Público-alvo

Costureiras autônomas e pequenos negócios domésticos de costura.

## Objetivo de Desenvolvimento Sustentável

ODS 8 — Trabalho Decente e Crescimento Econômico.

O projeto está relacionado à meta 8.3, ao propor uma ferramenta digital de apoio à organização de uma pequena atividade produtiva.

## Situação do projeto

Em fase de planejamento, prototipação e início da implementação técnica.

## Finalidade

Projeto acadêmico desenvolvido para aplicação prática dos conhecimentos de análise e desenvolvimento de sistemas.
